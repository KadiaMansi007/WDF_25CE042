# StudentHub
 
StudentHub is a static student portal built with semantic HTML5.
It allows students to register, login, view campus events, check their
dashboard, manage their profile, and share feedback with the college
administration.
 
## Problem Scope
A single static front-end that gives students one place to find campus
information (events, announcements, dashboard) and gives admins a place
to manage students, events, and feedback.
 
## User Roles
- Student: registers, logs in, views dashboard/events, edits profile, sends feedback
- Admin: manages students, events, and feedback submissions
- Visitor: views Home, About, FAQ, Contact before registering
 
## Key Modules / Pages
Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, Feedback
 
## Tech Stack
HTML5, CSS3, (JavaScript to be added in later practicals)
 
## How to Run
Open index.html in a browser, or serve the folder with a local server.
 
## Git Workflow
Each practical is committed separately with a clear commit message,
for example: "Practical 1: project setup, sitemap, wireframes" and
"Practical 2: semantic HTML5 pages with accessibility structure".
